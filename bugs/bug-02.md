# BUG-02: Хоосон маягт blank ном нэмдэг

Орчин: Reading List v2.0, Codex In-app Browser (version unavailable), Windows (version unavailable), 2026-10-15  
Урьдчилсан нөхцөл: App default 3 seeded book state-д байна.

## Дахин гаргах алхам
1. Гарчиг, Зохиолч, Он талбаруудыг бүгдийг хоосолно.
2. “Нэмэx” товчийг дарна.
3. Дараа нь нэг нэг талбарыг хоосон үлдээн, бусад хоёрт утга оруулж тус бүр илгээнэ.
4. Шинэ мөр, тоолуур, статус мессежийг шалгана.
5. Аппыг reload хийж мөр хэвээр эсэхийг шалгана.

Хүлээгдэж байсан: Гурван талбар бүгд заавал бөглөгдөнө; дутуу бол ном нэмэгдэхгүй, ойлгомжтой алдааны мессеж харагдана.
Бодит үр дүн: Бүх талбар хоосон үед “Ном нэмэгдлээ” гэж харуулаад хоосон мөр нэмсэн; Он 0 болж харагдаж, нийт тоо өссөн. Мөн гарчиг, зохиолч, эсвэл он тус бүрийг дангаар нь хоосон үлдээсэн үед бичлэгийг зөвшөөрсөн. Reload-ийн дараа хоосон бичлэг үлдсэн.
Ноцтой байдал: Major — утгагүй бичлэг өгөгдөлд нэмэгдэж, жагсаалтыг бохирдуулна.
Хавсралт: screenshot-ийг browser дээр авч шалгасан боловч орон нутгийн зураг файлд экспортлохыг browser safety policy хориглосон. API-ийн дутуу талбарын нотолгоо evidence/bug-02-curl.txt-д бий.
Олдсон аялал: Couch Potato, Saboteur.

Нэмэлт API баталгаа: POST /api/books-д {} илгээхэд HTTP 201 Created буцааж, title ба author хоосон бичлэг үүсгэсэн.
