# BUG-01: Нийт номын тоолуур жагсаалтын мөртэй таарахгүй

Орчин: Reading List v2.0 UI reproduction, Opera One 136.0.6008.80 (Chromium 152.0.7977.134), Windows 11 64-bit, 2026-10-15
Урьдчилсан нөхцөл: App default 3 seeded book state-д байна.

## Дахин гаргах алхам
1. Эхний 3 номтой app-ыг нээнэ.
2. Хүснэгтийн харагдаж буй номын мөрийг тоолно.
3. GET /api/stats болон GET /api/books хүсэлт илгээнэ.
4. stats.total-ийг жагсаалтын array length-тэй харьцуулна.
5. Хүчинтэй нэг ном нэмж, дараа нь устгаад зөрүү хэвээр эсэхийг шалгана.

Хүлээгдэж байсан: “Нийт ном” тоолуур хүснэгтэд буй номын тоотой тэнцүү.
Бодит үр дүн: Хүснэгт болон /api/books 3 ном харуулсан боловч /api/stats total=4 буцаав; UI “Нийт ном: 4” гэж харуулав. Хүчинтэй ном нэмэхэд total 5 болж 4 мөртэй, устгасны дараа total 4 болж 3 мөртэй хэвээр зөрсөн.
Ноцтой байдал: Minor — үндсэн CRUD ажиллаж байгаа ч хэрэглэгчийн тоолуур буруу.
