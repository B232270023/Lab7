# BUG-01: Нийт номын тоолуур бодит номын тооноос нэгээр их

Орчин: Reading List v2.0; Node.js v24.13.0; Codex In-app Browser (ажигласан User-Agent Chrome/155.0.0.0); Windows x64, 25H2, build 26200.9711; 2026-10-21.
API хэрэгсэл: curl.exe 8.21.0.
Урьдчилсан нөхцөл: Өмнөх node app.js process-ийг Ctrl+C-ээр зогсоож node app.js-ийг дахин асаасан; браузераа reload хийсэн; GET /api/books нь id 1, 2, 3 бүхий Тунгалаг Тамир, Clean Code, The Pragmatic Programmer гэсэн яг гурван ном буцаана. Page reload дангаараа server reset биш.

## Дахин гаргах алхам

1. http://localhost:3000/ үндсэн хуудсыг нээгээд гурван seeded мөрийг тоолно.
2. Нийт ном гэсэн тоог уншина.
3. GET /api/books болон GET /api/stats-ийг curl -i-ээр авч array length ба total-ийг харьцуулна.

Хүлээгдэж байсан: Спецификацийн “Нийт ном тоолуур хүснэгтэд буй номын тоотой тэнцүү” дүрмээр unfiltered жагсаалтад 3 байна.

Бодит үр дүн: Хүснэгт, /api/books нь 3 номтой; UI болон /api/stats total=4 гэж байна. Нэмэх/устгах үед зөрүү нэгээр хэвээр; номгүй үед [] боловч total=1 болсон.

Ноцтой байдал: Minor — Тоолуур хэрэглэгчийг төөрөгдүүлнэ; үндсэн нэмэх/устгах үйлдэл үргэлжилж байна.

Олдсон аялал: Fed-Ex.
