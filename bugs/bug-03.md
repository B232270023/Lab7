# BUG-03: Он 1000–2100 бүхэл тооны хязгаараас гадуур утгыг хүлээн авдаг

Орчин: Reading List v2.0, Codex In-app Browser (version unavailable), Windows (version unavailable), 2026-10-15  
Урьдчилсан нөхцөл: App default 3 seeded book state-д байна.

## Дахин гаргах алхам
1. Гарчиг ба зохиолч оруулна.
2. Он талбарт 2101 оруулж “Нэмэx” дарна.
3. 999, 1999.5 болон not-a-year утгаар тус тус дахин шалгана.

Хүлээгдэж байсан: Он нь 1000–2100 хоорондох бүхэл тоо; хязгаараас гадуур эсвэл бүхэл биш утгыг хүлээн авахгүй.
Бодит үр дүн: 999 ба 2101 хоёул нэмэгдсэн; 2101 хамгийн шинэ он болж тоолуурт гарсан. 1999.5 утга мөн нэмэгдэж хүснэгтэд 1,999.5 гэж харагдсан. not-a-year утга нэмэгдэж хүснэгтэд NaN гэж харагдсан. Хүчинтэй заагийн 1000 болон 2100 утгууд нэмэгдсэн.
Ноцтой байдал: Major — аппын үндсэн өгөгдлийн дүрэм зөрчигдөж, хуурамч он статистикт орно.
Хавсралт: screenshot-ийг browser дээр авч шалгасан боловч орон нутгийн зураг файлд экспортлохыг browser safety policy хориглосон.
